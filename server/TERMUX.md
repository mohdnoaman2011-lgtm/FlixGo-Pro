تشغيل الخادم على هاتفك (بدون استضافة)
الخادم يعمل على الهاتف نفسه ولا يقبل اتصالات من خارجه (127.0.0.1 فقط). يدعم الروابط المباشرة وصفحات الوسائط العامة، إضافة إلى منصات شائعة عبر yt-dlp عند توفر الصيغ المتوافقة (راجع README.md).
الخطوات
ثبّت Termux من F-Droid (نسخة المتجر القديمة على Google Play غير محدّثة).
انسخ مجلد server إلى هاتفك (مثلاً إلى Download/server)، ثم في Termux:
termux-setup-storage
cp -r ~/storage/downloads/server ~/server
cd ~/server
sh termux.sh
أول مرة يثبّت Node.js وPython وyt-dlp وffmpeg تلقائياً (إذا لم تكن موجودة). بعدها يظهر: «الخادم يعمل على http://127.0.0.1:8080».
اترك Termux مفتوحاً في الخلفية، وافتح FlixGo ← الإعدادات ← «خادم الاستخراج» ← الخادم المحلي ← حفظ.
الصق رابط صفحة وحلّله.
ملاحظات
لو أغلق النظام Termux لتوفير البطارية، استثنِه من تحسين البطارية في إعدادات الهاتف.
في المرات التالية يكفي: cd ~/server && sh termux.sh.
التطبيق يسمح بـ HTTP للعنوانين 127.0.0.1 وlocalhost فقط؛ بقية الاتصالات تبقى HTTPS.
هذا الإعداد يتطلب نسخة التطبيق المبنية بعد هذا التحديث (يضيف network_security_config).
