واجهة خادم الاستخراج (اختيارية)
التطبيق يتعامل مباشرة مع روابط ملفات الوسائط (.mp4 و.mp3 وغيرها). أما روابط صفحات المنصات فتحتاج خادماً تديره أنت يحوّلها إلى روابط ملفات مباشرة. عنوانه يُضبط في الإعدادات ← «خادم الاستخراج».
التطبيق لا ينفّذ استخراج المنصات محلياً. خادم server/ يدعم الروابط المباشرة والصفحات ذات الوسائط العامة، ويستخدم yt-dlp اختيارياً لدعم روابط عامة متوافقة من YouTube وTikTok وInstagram وFacebook وX/Twitter وVimeo وReddit وSoundCloud وTwitch. يتطلب ذلك تشغيل الخادم مع yt-dlp متاحاً في PATH (صورة Docker تثبّته تلقائياً). لا يدعم الحسابات الخاصة أو تسجيل الدخول أو DRM ولا يدمج مسارات الفيديو والصوت المنفصلة. التزم بشروط كل منصة وبحقوق المحتوى.
الطلب
GET {baseUrl}/resolve?url=<رابط الصفحة>
الرد الناجح (200، JSON)
{
  "title": "عنوان الفيديو",
  "author": "اسم القناة",
  "duration": 222,
  "thumbnail": "https://.../thumb.jpg",
  "formats": [
    { "label": "720p", "url": "https://.../video.mp4", "ext": "mp4", "size": 56623104, "audioOnly": false, "httpHeaders": { "User-Agent": "...", "Referer": "..." } },
    { "label": "128k", "url": "https://.../audio.m4a", "ext": "m4a", "size": 3145728, "audioOnly": true }
  ]
}
title وformats[].label وformats[].url مطلوبة؛ الباقي اختياري.
size بالبايت، ويُستخدم لعرض الحجم قبل التحميل.
url يجب أن يكون رابط ملف مباشراً؛ دعم Range مطلوب للاستئناف.
httpHeaders اختيارية، وتقتصر على ترويسات HTTP العامة اللازمة لبعض شبكات التوزيع. لا تمرّر ملفات تعريف ارتباط أو بيانات دخول.
الأخطاء
404 أو 422: تعذّر استخراج الرابط (يظهر للمستخدم: «تعذّر استخراج هذا الرابط»).
أي خطأ آخر أو انقطاع: «تعذّر الاتصال بخادم الاستخراج».
ملاحظات
إن كانت روابط الملفات التي يرجعها الخادم تنتهي صلاحيتها، فالاستئناف بعد مدة طويلة قد يفشل؛ أعد التحليل وابدأ تحميلاً جديداً.
استخدم HTTPS دائماً.
